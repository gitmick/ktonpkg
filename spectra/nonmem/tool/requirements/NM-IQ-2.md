# The licence is hidden configuration

NONMEM runs with a valid licence mounted read-only at /opt/nm/license/nonmem.lic. The licence is
never an input, never in the package, an image layer or a claim; the image's own licence is an
expired installation licence and does not count. Provisional (TQ P5, 25.11.2026).
